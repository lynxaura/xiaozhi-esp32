# LynxBox 嵌入式开发工作量评估范围（Scope Brief）

文档用途：为嵌入式软件工程师提供清晰、可估算的工作范围与验收口径。基于 `spec.md v3.11` 与 `Docs/LynxBox` 实现分析。

最后更新：2025-10-22

---

## 1. 项目基线（硬件/系统）

- 主控与存储：ESP32-S3-WROOM-1-N16R8（双核 240MHz，PSRAM 8MB，Flash 16MB，支持 OTA 双分区）
- 音频链路：双麦阵列（ES7210 + LMA3729T381×2，45mm），Codec ES8311 → NS4150B → 4Ω/3W 扬声器
- 传感器：QMI8658 IMU（动作：拿起/快摇/温摇/翻转/倒置/自由落体 等）
- 触觉反馈：1034 ERM 振动马达（PCA9685 PWM，10 种预设情感模式）
- 网络：WiFi 2.4GHz（BLE 用于配网，尚需落地）；4G（ML307，作为可选硬件版本）
- 框架现状：语音对话、打断、IMU 事件、触觉/音效反馈已具备；配网、电源、OTA、设备管理等需补齐。

代码参考（选摘）：
- 应用与协议：`main/application.cc`, `main/protocols/websocket_protocol.cc`, `main/ota.cc`
- 交互与事件：`main/boards/ALichuangTest/interaction/core/event_engine.cc`, `main/boards/ALichuangTest/interaction/upload/event_uploader.cc`
- 配置载入：`main/boards/ALichuangTest/interaction/config/event_config_loader.cc`
- 其他：`main/display/display.cc`, `main/boards/ALichuangTest/config.json`

## 3. 待实现与待验证清单（WBS/可估算项）

说明：以下分组列出要做的工作、对应规格条目、关键实现点与验收要点。建议在估算时给出复杂度（S/M/L/XL）与人日。

### 3.1 BLE 配网与绑定（高优先级）
- 规格关联：FR-007/008/009，NFR-015
- 工作内容：
  - 首次开机未绑定 → 自动进入 BLE 配对并语音引导（SC-006~009）
  - GATT 服务定义（WiFi SSID/PSK 传输、安全配对）
  - 绑定状态持久化（NVS，加密校验），自动重连逻辑
  - 配网/连接成功/失败提示音与错误处理
- 代码位置建议：`main/application.cc`（启动流转）、`components/ble_prov/*`（新建）
- 验收要点：≤3 分钟首次配网；成功率≥90%；断电重启自动连已存 WiFi。

### 3.2 M 键按钮逻辑（单击/双击/长按）
- 规格关联：FR-001a、FR-059/060/061
- 工作内容：
  - 状态机化：休眠/活跃/配网/升级模式下的按键语义与抑制
  - 双击识别算法：首次点击 300ms 等待第二击（≤500ms 窗口）；防抖；长按≥3s 进入配网
  - 交互反馈：单击短震、状态播报（“我在呢”）、网络切换播报（4G 版）
- 代码位置建议：`main/application.cc`（输入分发）、`drivers/button/*`（或复用现有）
- 验收要点：双击正确率≥95%，误触发<5%；各态一致。

### 3.3 电源管理（电量/充电/温度/休眠）
- 规格关联：FR-019~025c，NFR-004/009/016
- 工作内容：
  - 电池电量 ADC 读取、阈值提示（<15%/5%）与自动关机前告警
  - 充电状态 GPIO 检测、充电开始/完成/异常提示；允许充电时交互
  - 温度监测与保护：>50°C 停充并提示，<45°C 恢复；三次超温关机策略
  - 休眠策略与唤醒：10 分钟无交互休眠；按钮/动作唤醒；功耗测量与优化
- 代码位置建议：`power/*`（新建），`main/application.cc`
- 验收要点：休眠功耗≤待机 10%；唤醒≤2s；温度保护动作≤2s。

### 3.4 多 WiFi 管理与重连优化
- 规格关联：FR-010/010a/010b/010c，NFR-003/010
- 工作内容：
  - 支持最多 20 个网络，按 RSSI 选择最优，LRU 覆盖最久未用
  - 断线后 30s 内切换至其他可用网络；重连“静默/播报”阈值（<2 分钟静默，≥2 分钟播报）
  - 简易 APP 侧网络管理协议（可与 BLE 配网共用通道）
- 代码位置建议：`net/multi_wifi_manager.*`（新建），`wifi_station.cc`
- 验收要点：切换时延、成功率与提示策略符合规格。

### 3.5 系统提示音资源与调度
- 规格关联：FR-016/017/018，NFR-006/017，NFR-024（多语言资源）
- 工作内容：
  - 提示音资源梳理与目录规范（中/英 OGG/Opus，≤2MB）
  - 调度优先级：系统提示音 > AI 语音；事件触发≤1s开始播放
  - 开机/关机/联网/低电量/充电/异常等 13+ 类提示覆盖
- 代码位置建议：`audio/prompt_player.*`（新建/增强）
- 验收要点：事件到播放≤1s；不同类型音效区分明显；音量合适。

### 3.6 OTA 升级（分区/签名/灰度/回滚）
- 规格关联：FR-051~056，NFR-023（分区）
- 工作内容：
  - 分区表：`ota_0` 4MB + `ota_1` 4MB + `otadata`；独立资源分区规划
  - HTTPS OTA + 服务器证书校验 + 固件签名验证；断点续传
  - 灰度发布（设备 ID 哈希分桶）、升级进度上报、失败回滚
  - 电量门限检查（<30% 拒绝升级，充电优先）
- 代码位置建议：`main/ota.cc`, `partitions.csv`, `protocols/*`（API 集成）
- 验收要点：回滚可靠；签名校验必过；升级全程提示清晰。

### 3.7 设备管理（解绑/恢复出厂/激活锁）
- 规格关联：FR-026/027/028，NFR-013/019
- 工作内容：
  - 云端解绑/重置指令协议；本地 NVS 清除接口与安全擦除
  - 重置确认（长按≥10s），重置后自动进入配网
  - 激活锁（设备绑定态与功能限制策略）
- 代码位置建议：`device_mgmt/*`（新建），`main/application.cc`
- 验收要点：重置不影响固件与资源分区；凭证彻底清除。

### 3.8 多语言与资源热更新（可与 OTA 资源分区共用）
- 规格关联：FR-045~050，NFR-024
- 工作内容：
  - 编译期默认语言 + 云端动态切换优先级
  - 语言包格式（OGG/Opus ≤1MB）与资源分区热替换
- 代码位置建议：`i18n/*`（新建），`main/assets/zh|en/`
- 验收要点：切换无需重启；失败回退；容量与时延受控。

### 3.9 WiFi/4G 切换（仅 4G 硬件款，选做）
- 规格关联：FR-057~060，NFR-010c
- 工作内容：
  - 双击 M 键手动切换；开机仅一次自动选择（WiFi 优先，5s 超时转 4G）
  - 4G 模块（ML307）驱动/拨号/功耗管理；网络断线策略
- 代码位置建议：`cellular/ml307/*`（新建），`net/net_selector.*`
- 验收要点：切换 2~3s 内完成；提示与状态机一致；功耗指标达标。

### 3.10 日志与诊断（循环 100KB）
- 规格关联：FR-035，NFR-018
- 工作内容：
  - 系统事件与错误记录（不含隐私数据）；环形缓冲 100KB
  - 关键指标：网络失败、协议超时、传感器异常
- 代码位置建议：`diagnostics/logging.*`
- 验收要点：容量受控，刷新稳定，无敏感信息。

## 4. 交付物与验收标准（摘取核心）

- 端到端语音响应：≤2s（NFR-001）；打断响应：≤500ms（NFR-002）
- 首次使用体验：≤3 分钟完成配网并对话（NFR-015）
- 休眠与唤醒：无交互 10 分钟休眠；唤醒≤2s；休眠功耗≤待机 10%（NFR-004）
- 网络：断线 30s 内恢复/切换；多 WiFi 管理与重连提示策略（FR-010 系列，FR-061，NFR-003）
- 安全：TLS/WSS 全面启用；WiFi 凭证加密存储；OTA HTTPS + 签名校验（FR-029/056，NFR-011/013）
- OTA：灰度/回滚/进度；电量门限与提示（FR-051~055）

建议将每项验收具体化为测试用例（成功/异常/边界）。

## 5. 依赖与前置条件

- 云端 API：
  - 对话与事件：现有 WebSocket/MQTT 协议（`main/protocols/*.cc`）
  - OTA：`/api/ota/check`、`/api/ota/download`（需实现）
  - 设备管理/绑定：解绑/重置/语言配置等接口（需定义）
- 资源与资产：中/英文系统提示音（OGG/Opus），问候语与音效清单
- 分区表：满足 OTA 双分区 + 资源分区（16MB Flash 内规划）
- 硬件接口：电量 ADC、充电 GPIO、温度传感器/通道；（4G 版）ML307 通讯与天线设计

## 6. 风险与复杂点（估算时需考虑）

- BLE 与 WiFi 共存的干扰与配网稳定性（NFR-010a/b 测试）
- OTA 签名校验、断点续传与回滚的边界处理（断电/弱网）
- 电源与温度保护的时序可靠性与误判（传感器抖动）
- 多 WiFi 扫描/切换对实时对话的影响与“静默/播报”策略一致性
- 资源分区热更新与回退机制的原子性与容错

## 7. 阶段化实施建议（里程碑）

- 阶段 1（1–2 周）：BLE 配网、M 键逻辑、基础电源（电量/充电）、开/关机与联网提示音
- 阶段 2（2–4 周）：温度保护、低电量策略、多 WiFi 管理、网络重连提示、LED 状态指示、休眠功耗优化
- 阶段 3（1–2 月）：OTA（分区/签名/灰度/回滚/进度）、设备管理（解绑/重置/激活锁）、多语言热更新、诊断日志
- 可选阶段：4G 版网络选择与功耗管理
