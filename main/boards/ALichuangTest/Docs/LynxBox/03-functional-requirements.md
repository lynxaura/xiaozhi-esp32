### FR-001: 拨动开关
**规格要求**: 配备物理拨动开关,支持硬件级开关机控制

**实现状态**: ⚠️ **待确认硬件电路**

**需要验证**:
1. PCB是否有拨动开关电路
2. 是否通过电源管理芯片实现硬件断电

### FR-001a: M键按钮
**规格要求**: M键按钮支持单击、双击、长按,不同状态下响应不同操作

**实现状态**: ⚠️ **部分实现**

| 操作 | 状态 | 规格要求 | ALichuangTest实现 |
|-----|------|---------|------------------|
| 单击 | 休眠 | 唤醒设备 | ⚠️ 待验证 |
| 单击 | 活跃 | 状态播报+双次短震 | ❌ 待实现 |
| 双击 | 活跃 | WiFi/4G切换(4G版) | ❌ 未实现(仅WiFi版) |
| 长按3秒 | 任意 | 进入配网模式 | ⚠️ 待验证 |

**已有基础**:
- ✅ 按钮类: `button.h` - 继承自xiaozhi-esp32
- ✅ GPIO中断处理
- ⚠️ 双击识别算法 (spec.md:491行要求<500ms间隔)

**建议实现**:
```cpp
// ALichuangTest.cc中
void OnButtonPressed(ButtonEvent event) {
    switch (event) {
        case BUTTON_SINGLE_CLICK:
            if (is_sleeping) {
                WakeUp();
            } else {
                vibration_skill_->Play(VIBRATION_SHORT_BUZZ);
                TriggerAIStatusReport();  // "我在呢"
            }
            break;
        case BUTTON_DOUBLE_CLICK:
            // 4G版专属,WiFi版无响应
            break;
        case BUTTON_LONG_PRESS:
            EnterProvisioningMode();
            break;
    }
}
```
