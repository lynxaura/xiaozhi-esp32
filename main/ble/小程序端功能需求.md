# 小程序端功能需求文档

基于设备端蓝牙协议实现，小程序端需要实现以下功能模块。

## 1. 蓝牙连接和基础通信

### 1.1 设备扫描和连接
- **扫描蓝牙设备**
  - 搜索广播名包含 `"lxzn_wificfg-"` 前缀的设备
  - 显示设备列表，包括设备名称、信号强度
  - 支持刷新扫描结果

- **解析广播数据**
  - 解析厂商数据（厂商ID: 0xFFFF，测试用，可修改）
  - 提取设备信息：
    - 主版本号（3字节）
    - 测试版本号（1字节，0-255）
    - 电量百分比（0-100）
    - 充电状态（bit7标志位）

- **建立连接**
  - 连接到选定的BLE设备
  - 发现服务：UUID `0xFDD0`
  - 获取特性：
    - 写特性：`0xFDD1`
    - 通知特性：`0xFDD2`
  - 启用通知功能

### 1.2 数据通信协议
- **数据发送**
  - 通过写特性 `0xFDD1` 发送命令
  - 协议格式：`0x58 0x5A` + 命令字节 + 载荷数据
  - 根据MTU大小进行分包处理

- **数据接收**
  - 通过通知特性 `0xFDD2` 接收响应
  - 解析响应数据包
  - 处理分包数据重组

- **超时和重试机制**
  - 每个指令10秒超时
  - 连接间隔控制 ≤150ms
  - 失败重试策略

## 2. WiFi配网功能

### 2.1 WiFi信息管理
- **获取当前WiFi配置 (0x00)**
  - 读取设备当前连接的WiFi信息
  - 显示SSID和连接状态
  - 用于确认配网结果

- **WiFi扫描功能 (0x02)**
  - 触发设备扫描可用WiFi网络
  - 显示扫描结果列表
  - 包含SSID名称和信号强度
  - 支持刷新扫描

### 2.2 WiFi配置操作
- **设置WiFi配置 (0x01)**
  - 提供WiFi配置界面
  - SSID选择（从扫描列表或手动输入）
  - 密码输入界面
  - 安全类型选择（WPA/WPA2等）
  - 配置结果确认

### 2.3 高级WiFi管理 (0x06)
- **获取已配置SSID列表 (opt=0x00)**
  - 显示设备存储的WiFi配置
  - 支持查看多个已保存的网络

- **删除SSID配置 (opt=0x03)**
  - 选择要删除的SSID
  - 确认删除操作
  - 删除结果反馈

- **重新扫描 (opt=0x02)**
  - 与基础扫描功能相同
  - 在高级管理界面中调用

## 3. OTA升级功能

### 3.1 固件文件管理
- **文件选择**
  - 支持从本地选择固件文件（.bin格式）
  - 文件格式验证
  - 文件大小检查

- **版本信息解析**
  - 从文件名自动解析版本号（如：xxxx_1.3.6.bin → 1.3.6）
  - 版本格式：主版本.次版本.修订版本
  - 版本兼容性检查

### 3.2 OTA升级流程
- **发送文件信息 (0x03)**
  - 发送固件版本号（3字节）
  - 发送文件大小（4字节）
  - 计算并发送文件CRC32校验值（4字节）
  - 接收设备响应和数据包长度设置

- **文件数据传输 (0x04)**
  - 根据设备返回的packet_length进行分包
  - 按顺序发送数据包
  - 实时显示传输进度
  - 处理传输错误和重试

- **数据包校验 (0x05)**
  - 发送每个数据包的CRC32校验值
  - 验证设备计算的CRC32
  - 处理校验失败的情况

### 3.3 升级进度管理
- **进度显示**
  - 实时进度条显示
  - 传输速度显示
  - 剩余时间估算
  - 当前阶段提示

- **错误处理**
  - 升级失败提示
  - 版本不兼容警告
  - 网络异常处理
  - 提供重试选项

## 4. 设备管理功能
